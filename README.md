# ft_minecraft
## How to srart
1. Download library
```
make download
```
2. Lunch Game

for linux/arm64:
```
make
```
for mac/arm64:
```
make mac
```

## How to play
### *Key Bind*

**ESCAPE** exit the game

**W** move forward

**A** left

**S** move backward

**D** right

**SPACE** jump

**SHIFT** sneeze

**Q** sprint(holding)

**F3** change game mode

**F5** change perspective
